LinkLog v2.0 Product Specification
Focus: Context-Aware Learning Paths & UX Overhaul Design Language: NotebookML Aesthetic (Deep Blue/Purple gradients, Glassmorphism, Fluidity)

1. Core Logic: The "Dual-Engine" Architecture (核心逻辑：双引擎架构)
To solve the issue of "One prompt fits all," we are splitting the generation logic into two distinct modes based on user input.

Backend Logic (/api/generate-graph)
The API must evaluate the request body and route to the correct System Prompt.

Logic Flow:

IF userContext is empty/null → Trigger Mode A (Standard Exploration).

IF userContext has text → Trigger Mode B (Gap Analysis).

2. Prompt Engineering Strategy (Prompt 策略)
Mode A: Standard Exploration (全量模式)
Trigger: User only provides a goal (e.g., "Learn React").

Philosophy: Assume zero prior knowledge. Build a complete, ground-up roadmap.

System Prompt:

Markdown

### ROLE
You are an expert technical curriculum designer.

### TASK
Generate a complete, step-by-step knowledge graph for the goal: "{user_goal}".

### RULES
1. Assume the user is a beginner in this specific topic.
2. Include necessary foundations (e.g., if goal is React, include essential JS concepts).
3. Structure: Foundations -> Core Concepts -> Advanced Topics.

### JSON OUTPUT FORMAT
{
  "nodes": [
    { "id": "1", "label": "Foundations", "type": "concept", "description": "..." }
  ],
  "edges": [...]
}
Mode B: Gap Analysis (差量分析模式)
Trigger: User provides goal AND context (e.g., "Learn React", Context: "I know jQuery & HTML").

Philosophy: "Bridge the gap." Suppress obvious basics. Highlight paradigm shifts.

System Prompt:

Markdown

### ROLE
You are a "Bridge Learning" specialist.

### TASK
Create a learning path to master "{user_goal}" specifically for someone who already knows "{user_context}".

### RULES
1. **Gap Analysis:** Do NOT list basic concepts the user likely knows (based on their context).
2. **Bridge Nodes:** Identify specific concepts that link old knowledge to new (e.g., "Virtual DOM" vs "Direct DOM manipulation"). Mark these as type: "bridge".
3. **Safety Net:** If a basic concept is critical but often misunderstood (e.g., "JS `this` keyword"), include it but mark as type: "review".
4. **Focus:** Focus on the *differences* and *new patterns*.

### NODE TYPES
- "bridge": Connects old context to new goal.
- "new_concept": Standard new knowledge.
- "review": Critical basics to double-check.
- "target": The final goal.

### JSON OUTPUT FORMAT
{
  "nodes": [
    { "id": "1", "label": "Virtual DOM", "type": "bridge", "description": "Why we don't use $.append() anymore." }
  ],
  "edges": [...]
}
3. User Experience & Interface Flow (交互流程)
3.1 Home / Onboarding (首页优化)
Visual: Deep fluid gradient background.

Input Component:

Main Input: "What do you want to learn?" (Large capsule).

Action: Generate Map button.

"I have experience" Toggle: Small text/icon below main input.

Clicking it reveals: A secondary input "What do you already know?"

UX: This allows users to opt-in to "Mode B" right from the start.

3.2 The Loading Experience (加载体验)
Goal: Reduce anxiety during the 10-20s generation time.

UI Elements:

Skeleton Graph: Faint, pulsing gray nodes connected by lines in the background.

Status Ticker: A text line that cycles messages:

"Analyzing your goal..."

"Checking prerequisites..."

(If Mode B) "Bridging gap from your context..."

"Structuring knowledge paths..."

3.3 The Canvas & "Refine Context" (图谱与上下文修正)
Scenario: User generated a graph (Mode A), but realizes they want to filter out things they know.

UI Component: A floating button (Glassmorphism style) in the Top Right of the canvas.

Label: 🧠 Refine Context (or "I know some of this").

Interaction:

Click button -> Open Modal.

Modal asks: "Tell us what you already know to simplify this path."

User inputs: "I actually know JS basics."

Click "Update Graph".

System Action: Re-trigger API with goal + new context (Mode B).

Transition: Old graph fades out, new "leaner" graph fades in.

4. Visual Component Specs (组件样式规范)
Node Styles (React Flow)
Base Style: Glassmorphism cards (backdrop-blur-md, bg-white/5, border-white/10).

Type: "Target" (Goal):

Larger size.

Glow effect: shadow-[0_0_20px_rgba(59,130,246,0.5)] (Blue).

Border color: border-orange-500/50.

Icon: A small "Link/Chain" icon.

Type: "Review" (Mode B special):

Border color: border-yellow-500/50.

Label: "Review: [Concept Name]".

Sidebar (Drawer)
Animation: Slide in from Right.

Content:

Definition: (Generated by AI).

"Connection": (If Mode B) "Since you know {Context}, think of this as..." (Analogy).
